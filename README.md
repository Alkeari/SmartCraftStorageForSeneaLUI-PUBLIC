# SmartCraftStorage for SeneaL UI

SmartCraftStorage for SeneaL UI makes SeneaL UI's crafting window show the materials SmartCraftStorage finds in nearby chests.

---

## Availability

- [Nexus Mods](https://www.nexusmods.com/valheim/mods/4250)
- [Thunderstore](https://thunderstore.io/c/valheim/p/Alkeari/SmartCraftStorage_for_SeneaL_UI/)

## What It Does

- SeneaL UI's crafting window and build menu show your inventory plus what SmartCraftStorage finds in nearby chests, within SmartCraftStorage's crafting radius.
- SeneaL UI's own chest crafting, when its server allows it, takes from those same chests, so the numbers shown are what a craft uses.

## Requirements

- Verified on Valheim 1.0.17.

## Configuration

It has no settings of its own. SmartCraftStorage's crafting radius decides which chests count.

## Compatibility

- Client-side: only you need it, and a server does not.
- Removing it changes nothing in a world or a character.

## Support

- Include your game version, the mod version, and the other mods you have installed.
